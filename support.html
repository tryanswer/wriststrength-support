WristStrength support / 力量记录帮助

Release preparation is in progress. Availability and supported features will be stated in the official store listing.

应用正在准备发布。上线时间及支持功能以正式商店页面为准。

Record a session / 记录训练

Agree to local storage, add exercises, then create a routine from those exercises. Start the routine and save weight, reps, set type and completion. Select a recorded set to correct it; Undo removes the latest set. End keeps an ended session in history. Cancel keeps a cancelled record. An unfinished session can be resumed after closing the app.

同意本地保存后，添加动作，再用动作创建训练模板。开始训练，记录重量、次数、组类型和完成状态。选择已记录的一组可修正；撤销会移除最后一组。结束后进入历史；取消也会保留一条取消记录。关闭应用后可继续未结束的训练。

Units and history / 单位与历史

Choose the input unit before saving. Original kg/lb values remain in the archive. Display conversion uses 1 lb = 0.45359237 kg and rounds to 0.001. By exercise shows up to 12 ended sessions, using completed sets only; it is a record of entered values, not a strength estimate or training recommendation.

保存前选好输入单位。数据文件保留原始 kg/lb 数值。显示换算按 1 lb = 0.45359237 kg，四舍五入到 0.001。按动作查看最近最多12次已结束训练，仅统计已完成组。这是输入记录，不是力量估算或训练建议。

Larger text / 大号文字

On Apple, open Privacy & deletion and choose Use large text. On Huawei, use the text-size button near the bottom of the page. The local preference survives reopening and does not change your workout archive. Wear OS follows the device text-size setting.

Apple：打开隐私与删除，选择使用大号文字。Huawei：使用页面下方的文字大小按钮。本机设置会在重启后保留，不改变训练数据文件。Wear OS 使用设备的文字大小设置。

Retrieve your file / 取回数据文件

On Apple and Wear OS, install the phone companion and use the watch export action; open the companion to receive, then save/share the JSON file. A queued message means receipt is still pending. On Huawei, connect to a trusted private Wi-Fi network, open Import / export, start local transfer, then scan the link on your phone or computer. Keep the watch page open; exit or ten minutes closes the link.

Apple 与 Wear OS：安装手机伴侣应用，从手表发送导出，打开伴侣接收后保存或分享 JSON 文件。“已排队”表示尚未证明接收成功。Huawei：连接可信私人 Wi-Fi，打开导入／导出并开始本地传输，在手机或电脑扫码。保持手表页面打开；退出或十分钟后链接关闭。

Import validates the entire versioned file before merging. A duplicate ID, unsupported version or damaged file is rejected without partially importing records. After exporting, keep a private backup. Do not uninstall a damaged installation before preserving its data; contact support for recovery.

导入会先校验完整的版本化文件，再合并。重复 ID、版本不支持或损坏文件会整份拒绝，不导入部分记录。导出后请自行妥善备份。存储损坏时，保留数据前不要卸载应用；可联系支持协助恢复。
